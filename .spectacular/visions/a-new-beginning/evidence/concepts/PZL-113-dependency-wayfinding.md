# Dependency wayfinding before execution

## Core message

Map material unknowns and dependencies before committing persistent implementation when
work crosses several architectural boundaries or sessions.

## Value

Surfaces blocked paths and ordering constraints before code creates sunk cost.

## Assumptions

- The project complexity exceeds what a compact status view already resolves.
- Wayfinding output directly changes execution order or discovery work.

## Evidence and collisions

Supports PZL-061's narrow dependency semantics and conflicts with PZL-045's retirement
proposal. Mentioning Wayfinder as a tool is not evidence that Spectacular's current eight-
verb subsystem earns its cost.

## Trade-offs and recommendation

Dependency mapping reduces avoidable work but can become planning theater. Preserve the
behavioral test—does it reveal a different safe next action?—without presuming the surface.
