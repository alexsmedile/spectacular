# Minimal-metaphor hybrid

## Core message

Use memorable metaphor only for orientation and movement—Anchors, Missions,
Journeys, Waypoints—while keeping contracts, evidence, authority, readiness,
release, and records neutral.

## Value

Could provide personality and recall without sacrificing precision at high-stakes boundaries.

## Assumptions

- Users perceive one coherent mental model despite mixed metaphor sources.
- A stable rule clearly determines which terms remain neutral.

## Evidence and collisions

This is the source's strongest recommendation but tensions with its warning that
mixing worlds dilutes memory. Mission is space/organizational, Journey and Waypoint
are expedition/navigation, and Anchors is maritime/structural.

## Trade-offs and recommendation

Balanced character and precision versus an incoherent metaphor disguised as a
system. Define and test the boundary rule, not only the term list. Mixed until
cold-user interpretation is observed.
