# Compile bounded run context

## Core message

Before execution, compile only the current objective, relevant contracts/system
map, instructions, allowed scope, Git baseline, checks, retry budget, and stops.

## Value

Turns approved intent into a small executable authority envelope.

## Assumptions

- Relevant context can be selected deterministically enough to avoid unsafe omission.
- The bundle can be reconstructed after interruption.

## Evidence and collisions

Current request brief, skill routing, AFK authorization, and status provide pieces,
but no single versioned run-context contract exists.
Source 007 specifies graph-first selection, exact source-derived versions, secret
rules, probes, budgets, and human gates through a Mission compiler.

## Trade-offs and recommendation

Low retrieval cost and strong scope versus omission risk and another derived artifact.
Specify inputs and reconstruction rules before deciding whether to persist the bundle.
