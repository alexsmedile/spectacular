# Decision-density capability composition

## Core message

Prototype, grilling, logic simulation, review, and wayfinding may compose into one decision workflow,
but each becomes a skill only if it independently owns a complete job, substrate, and stable handoff.

## Value

Preserves a coherent high-density workflow without creating one shallow product per command.

## Assumptions

The capabilities share a useful routing contract and can remain optional without a circular
dependency on Spectacular internals.

## Evidence and collisions

Source 012 proposes five skills solely from command-shaped capabilities. That conflicts with the
agent-fleet reduction and MVP deferral goals and supplies no standalone-use or state-ownership proof.

## Trade-offs and recommendation

Test the workflow inside the refactor method first. At S07, classify each capability as core mode,
agent role, companion feature, or separate skill using the existing extraction acceptance test.
