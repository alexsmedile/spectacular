# Branch-first optioned grilling

## Core message

Resolve one coherent decision branch at a time using concrete options, consequences, and a visible
recommendation; ask sequentially when one answer materially changes the next question.

## Value

Reduces vague prompts and prevents premature implementation while keeping the human in authority.

## Assumptions

The interviewer can distinguish blocking choices from questions safely covered by defaults,
assumptions, evidence, or later implementation detail.

## Evidence and collisions

Source 012 simultaneously advocates many decisions per pass and one question per turn. The existing
Spectacular grill engine is implementation prior art, but “100% alignment” is not a measurable stop.

## Trade-offs and recommendation

Preview the branch and option matrix compactly, then traverse only dependent blockers one at a time.
Stop when remaining uncertainty is non-material, explicitly deferred, or covered by a contract.
