# Thin vertical graph slice

## Core message

Test one capability across the minimum architecture contracts, one Mission delta,
one guarded manifest/run, independent evidence review, reconciliation, and cold resume.

## Value

Measures whether the graph leaves the system more truthful before building search,
schedulers, every Mission type, or deployment automation.

## Assumptions

- One slice exposes enough graph and compiler friction to guide architecture.
- The implementation can remain disposable until the product world is chosen.

## Evidence and collisions

This extends Source 006's end-to-end acceptance test with explicit graph cost and
independent review. It is an evaluation method, not authorization to build production surface.

## Trade-offs and recommendation

High learning value versus prototype effort. If the graph world reaches the decision
round, require this spike before approving the workspace or compiler architecture.
