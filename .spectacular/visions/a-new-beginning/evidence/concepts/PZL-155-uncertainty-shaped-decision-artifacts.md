# Uncertainty-shaped decision artifacts

## Core message

Route uncertainty to the cheapest artifact that can resolve it: clarification for authority,
research for facts, a spike for feasibility, a logic harness for state, variants for experience,
and direct execution when scope is already bounded and reversible.

## Value

Avoids both low-fidelity overplanning and expensive prototypes that answer the wrong question.

## Assumptions

The uncertainty type, consequence, reversibility, and evidence threshold can be stated before
choosing the artifact.

## Evidence and collisions

Source 012 frames this as shift-left versus shift-right and five commands. Existing discovery and
risk-gate concepts show the routing problem is broader than command choice or ambiguity alone.

## Trade-offs and recommendation

Add an artifact-selection step to decision sessions. Prefer the cheapest sufficient evidence and
escalate fidelity only when the current artifact cannot settle the material choice.
