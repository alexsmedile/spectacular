# Proportional Vision entry

## Core message

Allow ambiguous ideas to enter Vision with a light first artifact and earn additional discovery
structure only as uncertainty and evidence require it.

## Value

Preserves deliberate discovery while reducing the temptation to bypass it for a premature spec.

## Assumptions

Observed avoidance reflects ceremony or discoverability, not proof that Vision has no value.

## Evidence and collisions

Issue #42 provides real user friction and corrects the lifecycle to `imagine → approved Vision →
draft SPC → approved spec → request/PLAN`. It also intersects the proposal to retire Vision.

## Trade-offs and recommendation

Test a one-file entry and clearer routing before removing or expanding the subsystem. Capture which
ideas still bypass it and why.
