# Mixed-initiative control continuum

## Core message

Let assistance move between suggestion, shared manipulation, delegated execution, and autonomous
completion according to task clarity, consequence, confidence, and explicit user authority.

## Value

Avoids forcing every task into either manual operation or opaque full automation.

## Assumptions

Users can understand the current authority mode and transitions preserve work and reversibility.

## Evidence and collisions

Source 013 proposes fluid transitions but does not address permission continuity or mode confusion.
Silent escalation from assistive to autonomous behavior would violate the authority model.

## Trade-offs and recommendation

Use a small explicit mode set with visible ownership, effects, and stop conditions. Permit automatic
downgrade toward safety; require authority for escalation toward consequential autonomy.
