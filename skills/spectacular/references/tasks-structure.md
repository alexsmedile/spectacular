# TASKS Structure

Use for TASKS authoring/refine. Top-level checkboxes are flush-left: `- [ ]` open, `- [x]` done,
`- [~]` deferred. Deferred items are reported separately. Group work under `### M<N> — name`.
Indented checkboxes are allowed as acceptance/decomposition checkpoints and never affect progress.
`v2` deferred work stays `- [~]`. Keep TASKS status aligned with PLAN and link `PLAN.md` in related.
