# Layered compounding memory

## Core message

Transform raw session evidence into successively smaller durable facts, patterns, and
operating guidance while retaining links back to provenance.

## Value

Allows future agents to retrieve the resolution level appropriate to the question.

## Assumptions

- Promotion criteria and contradiction handling prevent summaries from hardening errors.
- Subjective persona claims are kept separate from project facts.

## Evidence and collisions

Source 008 names L0-to-L3 layers but supplies no schema, evaluation, or retention method.
A systemic persona layer risks stale preference inference and authority confusion.

## Trade-offs and recommendation

Layering reduces retrieval volume while introducing summarization loss and duplicate truth.
Prototype fact-to-learning promotion inside existing records before new memory tiers.
