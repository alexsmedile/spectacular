# One domain per session

## Core message

Keep each focused review sitting to one decision domain and finish its evidence
capture before opening another subsystem.

## Value

Reduces context switching, partial judgments, and accidental coupling between
unrelated cleanup work.

## Assumptions

- Dependencies are recorded and can cross sessions without forcing interleaving.
- A domain is sized small enough for one coherent sitting.

## Evidence and collisions

This is an attention rule, not a requirement for one commit or request per domain.
Some evidence work may legitimately support several later decisions.

## Trade-offs and recommendation

Focus and reviewability versus slower cross-cutting synthesis. Use as the default
working cadence while keeping the concept database cross-linked. Strong.
