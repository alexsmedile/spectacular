# DEC-018 — Keep Spectacular as the primary lifecycle authority while GitHub provides collaborative surfaces

**Context:**
More projects are collaborative, but duplicating canonical lifecycle state between Markdown and GitHub would create drift.

**Evidence:**
User direction recorded by explicit command.

**Alternatives considered:**
Recorded in the cited user context or decision discussion.

**Decision:**
Keep Spectacular as the primary lifecycle authority while GitHub provides linked collaborative surfaces and evidence.

**Consequences:**
Spectacular owns intent, dependencies, scope, decisions, and verification interpretation; GitHub collaboration events are queried or linked rather than copied as a second authority. Exact projections remain deferred to SPC-003.
