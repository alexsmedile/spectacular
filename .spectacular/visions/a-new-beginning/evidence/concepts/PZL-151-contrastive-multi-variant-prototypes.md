# Contrastive multi-variant prototypes

## Core message

When experiential choices are hard to specify, build a small set of deliberately different
functional variants in one comparison surface so the human can react to real trade-offs.

## Value

Reveals layout, interaction, density, and state-policy consequences that prose often leaves abstract.

## Assumptions

- The variants differ on decision-relevant axes rather than styling noise.
- The prototype is disposable evidence and does not silently become production architecture.

## Evidence and collisions

This specializes PZL-112's prototype-as-evidence rule. The source provides plausible examples but no
evidence that exactly three variants or multi-variant work is always cheaper than focused discussion.

## Trade-offs and recommendation

Use two to four variants only when several viable archetypes exist and comparison cost is lower than
sequential iteration. Declare the axes each variant tests and record the selected composition.
