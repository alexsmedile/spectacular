# Graph-oriented workspace candidate

## Core message

Organize VISION, typed system contracts, Missions with deltas/evidence/runs, decisions,
learnings, and archive into one Markdown/Git-native graph workspace.

## Value

Makes the proposed information model visible and traversable in the filesystem.

## Assumptions

- Each collection earns independent storage and retrieval.
- Migration from current paths preserves history and compatibility.

## Evidence and collisions

The tree is substantially larger than Source 006's “minimal” workspace and resembles
the mature structure earlier sources criticize. No thin slice has earned the folders.

## Trade-offs and recommendation

Precise organization versus scaffold and lookup growth. Do not scaffold this tree;
prototype embedded contracts and grow directories on first demonstrated need.
