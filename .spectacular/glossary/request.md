# Request

In Spectacular, a **request** is a narrow, vertical execution slice. It owns
the [[plan]], [[task]]s, [[milestone]]s, verification, and delivery required to
realize a bounded part of an approved [[spec]].

A request is not a second capability contract. It may link to one contract, or
it may coordinate already-settled work directly.
