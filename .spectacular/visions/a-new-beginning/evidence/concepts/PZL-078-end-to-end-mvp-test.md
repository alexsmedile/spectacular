# End-to-end MVP acceptance test

## Core message

Prove on a real project that a cold agent can understand context, turn fuzzy intent
into approved scope, execute safely, produce a tested review artifact, reconcile
truth, and hand off coherently.

## Value

Measures the product promise rather than artifact count or command breadth.

## Assumptions

- The selected project and change are representative enough.
- Draft PR delivery is either available or replaceable by an equivalent artifact.

## Evidence and collisions

This test has not yet been run. It complements cold-start token measurement and
differential capability tests by evaluating the whole loop.
Source 007 adds an explicit graph-cost criterion and independent evidence review to the slice.

## Trade-offs and recommendation

High-signal but slower and scenario-sensitive. Adopt the method, then define at
least one non-GitHub variant for supported project types.
