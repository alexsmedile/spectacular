# Mission Control positioning

## Core message

Position Spectacular as “mission control for software projects.”

## Value

Memorable shorthand for shared context, coordination, evidence, and disciplined delivery.

## Assumptions

- Users read control as coherence and visibility, not centralized orchestration.
- The metaphor fits solo developers and varied project types.

## Evidence and collisions

The current PRD says Spectacular is not a project-management tool or multi-agent
orchestration platform. Mission Control also suggests approval authority,
real-time monitoring, deployment control, and operational command that the current
product may not provide. Source 006 proposes actual planning, autonomous run,
checkpoint, proof, and resume behavior that would make the positioning more
literal—but only by changing the current product boundary.

## Trade-offs and recommendation

Distinctive positioning versus overpromising and attracting the wrong category
expectations. Evaluate as messaging separately from canonical object names and
product scope. Disputed without user interpretation evidence.
