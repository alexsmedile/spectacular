# Spec

In Spectacular, a **spec** is the reviewed horizontal contract for a
[[capability]]. It records intended behavior, boundaries, constraints, and
acceptance conditions that may guide multiple [[request]]s.

A spec is approved when its spec pull request merges to the shared base. It is
not current implementation truth; code and executable tests hold that role.
