# Security policy

Report vulnerabilities privately through GitHub Security Advisories or the
repository's private vulnerability-reporting channel. Do not disclose a
potential vulnerability publicly before maintainers can coordinate a response.

`2.0.0-rc.2` is the currently supported release-candidate line. Verify the
SHA-256 checksum in `SHA256SUMS` before installing a release archive; the
installer refuses an archive whose selected checksum does not match.
