# PLAN Refine

Use only while refining a PLAN. Replace vague adjectives with a measurable result; turn
implementation verbs in milestones into demoable outcomes; number milestones; wrap request
dependencies as `[[slug]]`; and replace aspiration-only validation with a command, property,
artifact judgment, or observable behavior. A Goal must trace to PRD intent rather than repeat
frontmatter summary. Preserve superseded reasoning instead of deleting it.
