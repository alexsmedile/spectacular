# Mission-owned local semantics

## Core message

Treat features, bugs, fixes, refactors, research, spikes, feedback, and releases as
Mission meanings or owned objectives/runs unless they genuinely outlive the Mission.

## Value

Reduces global databases and keeps evidence beside the intent it serves.

## Assumptions

- Cross-Mission retrieval and reuse remain adequate through links or promotion.
- Each activity's authority can be preserved locally.

## Evidence and collisions

Current discovery types intentionally differ in code authority and durable value.
Fix knowledge, decisions, feedback, and roadmap intent may need to outlive one Mission.

## Trade-offs and recommendation

High local cohesion versus loss of reusable corpora and fleet-wide queries. Define
promotion criteria before collapsing any global type.
