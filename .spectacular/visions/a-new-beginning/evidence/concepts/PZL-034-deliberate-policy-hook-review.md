# Deliberate policy-hook review

## Core message

Review each policy hook explicitly and permit “keep unchanged” as a valid outcome
rather than retaining the surface only because nobody examined it.

## Value

Turns inherited complexity into an intentional contract.

## Assumptions

- Each hook can be evaluated against real enforcement value and cost.
- Hook count is not itself the success metric.

## Evidence and collisions

Current POLICY has nine hooks, while the source refers to eight. Removing POLICY
from the default scaffold and removing runtime policy behavior are separate decisions.

## Trade-offs and recommendation

Intentional governance versus review cost and false pressure to change something.
Strong decision hygiene; inventory current hooks and evidence before any cut.
