# Usage-based collection pruning

## Core message

Remove collections whose actual use does not justify their CLI, rules, doctor,
and reference surface.

## Value

Can delete capability and maintenance cost together rather than merely hiding
empty folders.

## Assumptions

- Local record counts capture meaningful use.
- No external workflow or preventive value justifies the capability.

## Evidence and collisions

Sessions has only an index and debugs no functional traces, but AFK has two run
records and a branch ledger. Visions now owns this active refactor. Empty or sparse
storage is not proof that the workflow is dead.

## Trade-offs and recommendation

Large surface reduction versus deleting recently added or externally useful
capabilities on weak evidence. Evaluate each collection independently using the
survival rubric and replacement analysis. Disputed as a batch.
