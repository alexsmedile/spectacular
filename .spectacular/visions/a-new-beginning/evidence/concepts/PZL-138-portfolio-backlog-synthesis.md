# Portfolio backlog synthesis

## Core message

Periodically retrieve the complete issue portfolio, normalize proposals and comments, expose
dependencies and contradictions, and classify the next decision for each cluster.

## Value

Turns a chronological backlog into an actionable decision surface without closing or rewriting it.

## Assumptions

Retrieval completeness and snapshot date are recorded, and synthesis never mutates GitHub by
default.

## Evidence and collisions

Issue #30 is directly prototyped by Source 011: 23 issues became evidence cards, dependency chains,
actionability lanes, and 22 atomic concepts.

## Trade-offs and recommendation

The synthesis can become stale or overconfident. Keep links to the raw issues, label inferences,
and rerun only at explicit review checkpoints.
