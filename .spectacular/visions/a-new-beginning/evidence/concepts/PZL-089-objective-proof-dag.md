# Objective DAG with proof prerequisites

## Core message

Mission objectives remain outcome-oriented while declaring prerequisite relationships
and the proof each objective requires.

## Value

Preserves adaptive file-level work without losing execution order or verification intent.

## Assumptions

- Objective dependencies are stable enough to persist.
- DAG complexity remains small for ordinary Missions.

## Evidence and collisions

Current milestones, tasks, wayfinding dependencies, and validation contain related
signals. A new DAG could consolidate or duplicate them.

## Trade-offs and recommendation

Clear readiness versus planning overhead. Use dependencies only when they change safe
ordering; require proof fields for every objective.
