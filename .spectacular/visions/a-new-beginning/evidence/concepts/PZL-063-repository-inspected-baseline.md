# Repository-inspected project baseline

## Core message

Have init inspect the repository and propose concise, human-confirmed PROJECT and
SYSTEM baselines covering intent, constraints, structure, interfaces, and commands.

## Value

Cold agents receive grounded context rather than empty templates or a full graph.

## Assumptions

- Repository inspection can propose accurate product intent and operational rules.
- Two files are clearer than the current Anchor set.

## Evidence and collisions

PRD, AGENTS, PRINCIPLES, ARCHITECTURE, STACK, and specs index already own parts of
this information. Replacement, projection, and duplication are unresolved.

## Trade-offs and recommendation

Useful cold-start synthesis versus costly/stale generated prose and authority
collision. Test the information contract before choosing filenames or replacement.
