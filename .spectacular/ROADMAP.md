# Product direction

Current work prioritizes durable context, minimal files, and predictable placement.
Plans describe active changes; campaigns connect independently useful delivery
slices only when that extra view helps.

## Current focus

- Small linked objects with basic metadata and folder-agreed types.
- Durable native planning through the [Skill route](../skills/spectacular/references/plan.md).
- Clear plan/spec/Contract and audit/Review/Handoff boundaries.
- Optional Missions, preserved mechanical Contracts and historical records.

[Current work](plans/durable-plan-mode.md) · [Earlier implementation](plans/knowledge-first-optional-governance.md)

## Established advanced surfaces

The [context-sandwich campaign](campaigns/context-sandwich-steering.md) records
prior governance and execution work. Its historical Missions are not this task’s
active execution state. Charter compilation, isolated delegation, and formal proof
remain available when explicitly selected.

## Future considerations

Improve navigation and context quality based on actual project use. Additional
multi-agent or external proof integrations are possibilities, not an obligatory
roadmap or an automatic enrollment path. A new plan owns any concrete proposal.
