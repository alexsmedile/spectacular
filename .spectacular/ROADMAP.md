# Product direction

Delivered v3.0 established durable context and optional governed execution. v3.1
added linked requirements and optional drafting methods. Current maintenance
aligns naming, navigation, and archive placement with those shipped behaviors.

## Current focus

- One content owner for each independently useful need, definition, or outcome.
- Small linked objects with compact metadata and folder-agreed types.
- Clear Requirement/Spec/Plan/Contract and Audit/Review/Handoff boundaries.
- ONTOLOGY.md for the domain model, manual reading routes, and generated JSON inventories.
