# Coherent vocabulary system

## Core message

Choose an explicit vocabulary world and naming boundary instead of accumulating
space, expedition, landing, and neutral terms opportunistically.

## Value

Consistent mental models may improve recall, documentation coherence, and the
agent's ability to infer relationships from names.

## Assumptions

- Metaphorical consistency improves comprehension across cultures and project types.
- Existing users gain more than they lose through relearning.

## Evidence and collisions

The source provides a detailed option map but no user or retrieval evidence. Its
own recommended hybrid tensions with the “one world” principle. A strict metaphor
can also make high-stakes concepts less precise.

## Trade-offs and recommendation

Memorability and product character versus jargon, migration, and metaphor leakage.
Test candidate vocabularies on cold-start interpretation and mixed project types.
Promising design principle; not an automatic mandate for themed names.
