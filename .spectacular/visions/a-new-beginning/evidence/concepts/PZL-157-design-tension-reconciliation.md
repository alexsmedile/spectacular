# Design-tension reconciliation matrix

## Core message

Name the competing goals and non-negotiable constraints before generating solutions, then compare a
small set of reconciliation archetypes through their mechanism, failure mode, fallback, and cost.

## Value

Prevents layouts or implementation details from hiding the value trade-off that actually needs a decision.

## Assumptions

The tension is genuine, material, and not removable by correcting a false requirement or missing fact.

## Evidence and collisions

Source 013 invokes TRIZ but supplies no evidence that a named framework resolves UX choices. The
matrix structures reasoning; the human still owns the accepted trade-off.

## Trade-offs and recommendation

Add tension mapping before variant generation. Use two to four genuinely different reconciliation
models and state which goal each sacrifices rather than claiming a cost-free synthesis.
