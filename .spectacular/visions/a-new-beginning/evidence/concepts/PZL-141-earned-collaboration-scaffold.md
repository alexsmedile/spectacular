# Earned collaboration scaffold

## Core message

Offer GitHub collaboration files when a repository demonstrates or explicitly requests that need,
rather than adding `.github/` policy surface to every initialization.

## Value

Can improve issue and pull-request consistency without violating the minimal scaffold principle.

## Assumptions

A kit, explicit flag, or detected remote provides a trustworthy opt-in signal.

## Evidence and collisions

Issue #35 proposes collaboration scaffolding, while Sources 001 and 006 argue that structure must
be earned. Ownership between Spectacular, a pack, and GitHub tooling is unsettled.

## Trade-offs and recommendation

Treat it as an optional collaboration pack or grow-on-first-PR suggestion. Keep the default init
floor unchanged.
